# The Lost Camera v0.2.2

## New

- Added a dedicated **Darkroom Table GUI** for developing physical prints from album photographs.
- Added a visual negative selection grid, selected-photo preview, photographic paper counter and development progress feedback.

## Changes

- Physical prints are now developed directly through the **Darkroom Table** instead of from the full-screen photo viewer.
- Darkroom development now validates the exact table being used server-side.

# The Lost Camera v0.2.1

## New

- Added **Before / Restored** photo pairs for individual ruin discoveries.
- Added **Photographic Paper** for making physical copies of photographs.
- Added the **Darkroom Table** and a short development process for photographic prints.
- Added **Photographic Prints** that preserve the original photograph without consuming the album entry.
- Added **Photo Frames** that display the player's real photograph in the world.

## Changes

- Improved the camera shutter blackout, recoil and mechanical sound feedback.
- Ruin photographs now remember whether they show the site **before** or **after** restoration.
- Album ruin entries now emphasize the visual Before / Restored comparison.

## Fixes

- Restored ruin photographs no longer report that they triggered a second restoration.
