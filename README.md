# The Lost Camera

A NeoForge mod for Minecraft 26.2.

The Lost Camera adds an old camera, collectible photographs, a personal photo album, and forgotten ruins that can be discovered and restored through photography.

## Features

- Use the Lost Camera to capture in-game photographs.
- Store photographs in a personal server-side album.
- Discover ruined structures in the world.
- Restore documented ruins after photographing them.
- Browse discovered ruins, favorites, archives, and photo previews from the album interface.

## Requirements

- Minecraft 26.2
- NeoForge 26.2.0.41-beta
- Java 25
